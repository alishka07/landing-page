# SuBulaq — лендинг

Одностраничный сайт проекта автономного мониторинга воды. Без сборки и зависимостей:
чистый HTML + CSS + JS. Открывается двойным кликом по `index.html`.

```
index.html      разметка, все 13 секций
styles.css      дизайн-система и все компоненты
script.js       навигация, вкладки платформы, выноски, FAQ, форма
assets/         рендеры судна и фото команды (см. assets/README.md)
```

Локальный просмотр с сервером (нужен для корректной работы шрифтов в некоторых браузерах):

```bash
npx serve .
# или
python -m http.server 8000
```

## Что нужно заменить перед публикацией

В коде эти места помечены комментарием `<!-- TODO -->`.

**1. Рендеры судна** — см. [assets/README.md](assets/README.md). На первом экране стоит
`assets/vessel-hero.png` — кадр судна на воде во весь экран. Чтобы поставить другой,
достаточно заменить файл. В секции «Аппарат» тот же кадр подставляется автоматически
(затемнённый, с выносками по узлам), пока вы не положите `vessel-tech.png`.

**2. Технические характеристики** (секция «Аппарат»). Значения — реалистичные ориентиры
для аппарата этого класса, но они **не проверены по вашему прототипу**. Сверьте каждую
строку: длина, масса, автономность, скорость, глубина забора, IP, диапазон температур.
Под таблицей стоит оговорка «уточняются по результатам полевых испытаний» — если
характеристики уже финальные, её стоит убрать.

**3. Команда** — имена, роли, био и фото трёх человек.

**4. Признание** — точные названия конкурсов, места и годы. Формулировки про NIS Incubator
и Astana Hub намеренно осторожные («участник программы», «интерес к проекту»).
Не усиливайте их до «победитель» или «резидент», пока это не подтверждено документально —
на защите такие вещи проверяют.

**5. Контакты** в футере: почта, телефон, ссылка на Instagram.

**6. Тарифы** — сейчас у всех трёх «по запросу». Если по Eco и Pro есть конкретные цифры,
поставьте их: конкретная цена сильно повышает конверсию заявки.

**7. Отправка формы** — сейчас заявка выводится только в консоль браузера.
В [script.js](script.js) найдите комментарий `TODO: подключить отправку`.
Самое быстрое — [Formspree](https://formspree.io): создать форму и заменить обработчик на

```js
fetch('https://formspree.io/f/ВАШ_ID', {
  method: 'POST',
  headers: { 'Accept': 'application/json' },
  body: new FormData(form)
});
```

## Источники данных в секции «Проблема»

Все четыре цифры взяты из публичных источников, ссылки стоят прямо в карточках:

- **373 створа на 134 водных объекта** — [Казгидромет, «Об экологическом мониторинге»](https://www.kazhydromet.kz/ru/ecology/ob-ekologicheskom-monitoringe)
- **17 аккредитованных лабораторий (ISO/IEC 17025)** — [Kazinform, интервью о мониторинге водных объектов](https://www.inform.kz/ru/kak-provoditsya-monitoring-kachestva-vodnyh-ob-ektov-v-kazahstane_a3696278)
- **~30 % хозбытовых стоков очищается безопасно** — [UN-Water, SDG 6 Data · Kazakhstan](https://www.sdg6data.org/en/country-or-area/kazakhstan)
- **49 % водных объектов с хорошим качеством воды** — [UN-Water, SDG 6 Data · Kazakhstan](https://www.sdg6data.org/en/country-or-area/kazakhstan)

Цифры проверялись 8 сентября 2026 года. Перед защитой стоит перепроверить — Казгидромет
обновляет данные ежеквартально, и число створов меняется. Если найдёте свежий
информационный бюллетень с более сильными цифрами по вашему региону, замените:
локальные данные по конкретной области убеждают жюри лучше республиканских.

**Сознательно не использовано:** периодичность отбора проб «три раза в год». Эта цифра
встречается в прессе, но по официальной методике периодичность зависит от категории
водоёма, и единого числа нет. В тексте секции стоит корректная формулировка
«периодичность зависит от категории водоёма» — она не менее убедительна и не разваливается
при проверке.

## Позиционирование, заложенное в текст

Два содержательных решения, которые стоит сохранить при правках:

**Классификация источника — главный аргумент.** Датчики в воде есть у многих;
ответ на вопрос «кто сбросил» — нет. Поэтому пять типов источников вынесены
в отдельную секцию, а не спрятаны в список возможностей.

**Честность про юридический статус данных.** В FAQ прямо сказано: непрерывные измерения —
это индикаторный контроль, юридически значимое заключение даёт аккредитованная лаборатория,
а аппарат отбирает контрольную пробу в момент события и приводит лабораторию к нужной точке
вовремя. Это первый вопрос, который задаёт любой человек из водоканала или надзора.
Заявка «мы заменяем лабораторию» разваливается на первой же встрече — эта формулировка нет.

Так же осторожно сформулировано ограничение по зиме: ледостав признан прямо, с указанием,
что рабочий сезон покрывает паводок — период основной части сбросов.
