# Изображения

Положите файлы сюда с точно такими именами — страница подхватит их автоматически.

**`vessel-hero.png` уже стоит на первом экране** — кадр во весь экран, поверх него
лежат светлая вуаль, слово-подложка SUBULAQ и карточки-выноски. Чтобы поменять судно,
просто замените файл: разметку править не нужно.

Первый экран собран слоями (см. `.hero__media` в `styles.css`):

1. `.hero__photo` — сам кадр, `object-fit:cover`;
2. `.hero__ghost` — крупное слово-подложка;
3. `.hero__photo--mast` — та же фотография по круглой маске в зоне мачты: мачта и антенны
   перекрывают слово, шов не виден, потому что пиксели совпадают с нижним слоем. Если
   у нового кадра мачта в другом месте — подвиньте `radial-gradient` в маске;
4. `.hero__veil` — белые градиенты, чтобы заголовок и подписи читались поверх кадра.

В секции «Аппарат» пока показывается пунктирный слот с подсказкой.

## Выноски на схеме аппарата

Пять точек в секции «Аппарат» позиционируются в процентах от размера контейнера.
После подстановки своего рендера подгоните координаты в [index.html](../index.html) — найдите `class="pin"`:

```html
<button class="pin" style="--x:26%;--y:32%" data-pin="Мультипараметрический зонд" data-desc="...">1</button>
```

`--x` — отступ слева, `--y` — сверху. Текст выноски меняется в `data-pin` (заголовок) и `data-desc` (описание).

## Где взять рендер

Судно можно отснять на воде и вырезать фон, либо отрендерить в Blender/KeyShot.
Для первого экрана важны: контровой свет, брызги по борту, отражение в воде,
камера чуть ниже линии борта — судно должно читаться крупно и «в движении».
